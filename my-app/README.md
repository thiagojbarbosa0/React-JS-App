# Lumen Gallery — Client

This is the React frontend for Lumen Gallery.

See the [project root README](../README.md) for full setup instructions
(installing dependencies, running the API server, environment variables,
and per-OS terminal commands).

Quick start (assumes the API server in `../exp5/server` is already running):

```bash
npm install
npm start
```

Opens the app at http://localhost:3000.
